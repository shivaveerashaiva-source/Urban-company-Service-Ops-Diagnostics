This project is about creating a stake-holder specific dashboard using Tableau Public platform. first a raw messy periodic data of 'Urban Company" received is cleaned, processed and used to create accurate meaningful easily understandable results. 
A dashboard is created in Tableau public which uses accurate error-free data from SQLlite, Spreadsheet and Python tools, cross-verified systematically for data accuracy.
Initially a database is built, cleaned and exported to a CSV file. This CSV is imported into a spreadsheet and the values are cross-verified. This error-free data is taken into Tableau public to create a Dashboard which gives a stakeholder-specific narrative.
All the necessary files are stored in Github public.
